# Limitations and Threats to Validity

- Only five independent runs were available per method.
- Statistical non-significance does not demonstrate equivalence.
- Some Static and AMF-HPA runs had latency coverage below 100%.
- The latency metric excludes authentication and security-mode processing.
- Baseline evidence originated from the previous experimental environment.
- DA-SACO experiments used the current environment except R1.
- DA-SACO reduced aggregate AMF CPU P95 relative to AMF-HPA and Open5GLoS, but recorded the highest aggregate AMF memory P95.
- DA-SACO also recorded the highest MongoDB memory P95.
- One additional AUSF replica in DA-SACO R4 remained idle during the verification window.
- Unclassified non-completions are evidence gaps, not confirmed protocol causes.
- The 1000-UE workload with a 120 ms launch interval does not establish behavior under every workload level.
